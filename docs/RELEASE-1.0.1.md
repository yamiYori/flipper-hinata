# HINATA USB Reader 1.0.1

[Simplified Chinese](RELEASE-1.0.1-zh-cn.md)

Adds a music arcade cabinet icon to the application list and updates the Unleashed build to unlshd-095 / API 88.26.

Choose the build matching your firmware:

- **Official 1.5.1 / API 88.2**: `hinata_usb-official-1.5.1.fap`
- **Unleashed unlshd-095 / API 88.26**: `hinata_usb-unleashed-095.fap`

Rename the chosen file to `hinata_usb.fap` and copy it to `/ext/apps/USB/`. Both builds target Flipper Zero F7.

The ZIP includes both FAPs, complete source, the icon and documentation. Verify downloads with `SHA256SUMS`.

See the [README](../readme.md), [compatibility checks](VALIDATION.md) and [contribution guide](../CONTRIBUTING.md).
