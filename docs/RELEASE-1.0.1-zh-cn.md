# HINATA USB Reader 1.0.1

[English](RELEASE-1.0.1.md)

为应用列表加入音游机台图标，并将 Unleashed 构建更新至 unlshd-095 / API 88.26。

按所用固件选择成品：

- **官方 1.5.1 / API 88.2**：`hinata_usb-official-1.5.1.fap`
- **Unleashed unlshd-095 / API 88.26**：`hinata_usb-unleashed-095.fap`

将选中的文件重命名为 `hinata_usb.fap`，复制到 `/ext/apps/USB/`。两种成品均适用于 Flipper Zero F7。

ZIP 包含两种 FAP、完整源码、图标和文档，可使用 `SHA256SUMS` 核对下载。

参见[使用说明](../readme-zh-cn.md)、[兼容性验证](VALIDATION.md)和[贡献指南](../CONTRIBUTING-zh-cn.md)。
